# Little Lemon Restaurant Website

A small multi-page static website for a fictional Mediterranean restaurant, built with plain HTML and CSS.

## Pages
| Page | File | Styles |
|---|---|---|
| Home | `index.html` | `practice7.css` |
| Menu | `menu.html` | `menu.css` |
| Book a table | `book.html` | `book.css` |
| About | `about.html` | `about.css` |

`practice7.html` is an earlier practice version of the home page. Logos are `logoo1.png` and `logoo2.png`.

## Run
No build step. Open `index.html` in a browser.
